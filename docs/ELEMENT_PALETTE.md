# 右侧元素栏

画布右侧、垂直滚动条左侧提供 36 DIP 宽的元素栏，按钮为 28 × 28 DIP，与紧凑工具栏接近。默认顺序为 C、H、O、N、P、F、Cl、Br、I、Si、B。

- 点击元素：将选中的原子改为该元素，并进入元素绘制状态。点击空白处添加原子，点击已有原子替换元素；支持撤销、重做。Esc 或选择其他工具可退出。
- 点击顶部周期表图标：打开含 118 种元素的周期表。先选择元素，再点“使用元素”。Enter 使用当前元素，方向键移动选择，Esc 关闭。
- “固定到侧栏”与“取消固定”：维护常用元素列表。Space 可切换固定状态；元素格右上角的小标记表示已固定。固定元素超过可见高度时，使用滚轮或栏底翻页按钮查看。
- “元素颜色…”：保存全局显示颜色。画布上的原子、输入的化学式和官能团展开后的原子都会使用相应元素的颜色。例如将 N 设为蓝色后，NH₂ 会显示蓝色；如果还给 H 指定了颜色，H₂ 使用氢的颜色。“恢复默认颜色”清除此元素的全局颜色设置。右键点击侧栏元素也可打开该元素的周期表设置。

常用元素和颜色保存在应用现有 `interface.ini` 的 `[ElementPalette]` 节，按应用现有的便携版／商店版配置路径规则存储。

周期表标题、操作按钮、说明、状态提示和保存错误已接入应用现有的 15 种语言。切换语言时可直接刷新已打开的周期表，化学元素符号与标准周期表排列保持不变。长按钮文字按可用宽度调整字号；阿拉伯语说明使用从右到左排版。

检查：设置环境变量 `MOLECULE_STUDIO_ELEMENT_CHECK=1` 后运行 `MoleculeStudio.exe --chrome-check <已有输出目录>`，覆盖周期表坐标和点击区域、栏与滚动条布局、原子添加／替换／撤销、颜色及固定列表持久化，并生成界面截图。检查完成会恢复原有元素栏设置。

语言回归入口为 `studio/tools/check_element_language.cpp`，检查 14 条新增文案的全部 15 个语言版本、状态提示占位符和已创建窗口的标题刷新。多语言界面检查可通过现有 `MOLECULE_STUDIO_DATA_DIR` 环境变量隔离测试设置，不修改用户的语言选择。
