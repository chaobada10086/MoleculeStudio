# MoleculeStudio 0.95-20261108 版本说明

发布日期：2026-11-08。对应任务书（11.8 凌晨任务书 + 追加需求）全部条目。

## 安装包（四组件）

| 组件 | 文件 | 说明 | 依赖 |
| --- | --- | --- | --- |
| Core | MoleculeStudio-0.95-20261108-Core-win64.zip | 主程序、化学/核磁/三维运行时、内置 AI 绘图 Skill、手动更新下载器 | 无 |
| AI 基础 | MoleculeStudio-0.95-20261108-AIBasic-addon-win64.zip | AI 助手、检索、对话画图桥接（约 74 KB，不装 AI 模组也能用 Core 内 Skill） | Core |
| AI 高级 | MoleculeStudio-0.95-20261108-AIAdvanced-addon-win64.zip | 内置 DSH 运行时的 AI 高级绘图（约 758 MB，含第三方许可/源码） | AI 基础 |
| 图片识别 | MoleculeStudio-0.95-20261108-OCSR-addon-win64.zip | 本地图片/PDF 转结构（2026-11-08 精简模块，重新打包后约 795 MB） | Core |

四个 ZIP 都带 `MoleculeStudio/` 根目录，解压合并到同一目录；版本必须一致。AI 高级不能脱离 AI 基础单独安装。

## 任务书条目完成情况

1. **官能团表与自动大小写**：目录扩充到 369 条源数据/361 条编译条目（新增 Bpin、pin、Ns、DIBAL、Li、MgBr、Cp、Tr、SnBu3 等）；修复元素同名导致 `cn` 永不补全的问题，`cn→CN`（可展开氰基）、`bpin→Bpin`、`tbu→tBu` 等；精确元素符号（Co/Cn）保持原样；歧义键不猜测。清单见 `docs/FUNCTIONAL_GROUPS.md`。
2. **外部粘贴格式确认**：键长/键宽/字体与当前文档不同时弹窗，默认采用复制源格式；画布为空时静默整体采用源格式；本程序内部复制不打扰。整个粘贴一次撤销。
3. **命名与结构自动成组**：结构转命名自动把命名与结构编组；结构变化后命名出现红框，悬停提示“结构已经发生变动”；撤销/重做、原生与 CDXML 重载、解组行为正确。
4. **默认字体**：内联文字默认 Arial 10，与 ChemDraw 默认一致；导入无字体信息的 CDXML 回退 Arial；编辑旧文字不再污染新建默认字体。
5. **文本对象直接改格式**：框选文字后可点字体/字号/加粗/斜体/下划线/上下标/颜色/对齐，无需进入编辑框；支持组内文字与撤销。
6. **工具栏默认展开**：初次安装/无配置时默认展开；用户保存过的收起偏好仍被尊重。
7. **AI 未配置提示**：AI 助手窗口显示提示条与“配置 API”按钮，直达设置-AI 页；补全后自动消失；发送/测试连接时也会提示。
8. **AI 生成居中**：本轮新增内容整体平移到当前可见画布中心，多对象整体居中，超大结果仅缩小不放大；既有对象不被搬动；一次撤销。
9. **四组件安装器 + AI 基础/高级拆分 + 低分辨率修复**：四卡片显示各自发布版本、包体积，底部显示所选合计体积；AI 高级包含内置 DSH 运行时（约 758 MB），AI 基础仅桥接代码（约 74 KB）；依赖与安装/卸载顺序、勾选高级自动带基础；schema2 清单，兼容旧 schema1；1024×600 / 125% / 150% 下界面自适应可操作；AI 设置新增“另存 AI 绘图 Skill…”；Skill 随 Core 内置，不装 AI 模组也能导出。
10. **手动更新入口**：设置“更新与关于”页提供“打开更新下载器…”；下载器随 Core 提供；只有用户点击才启动，绝不自动检查更新或联网。
11. **Core 依赖瘦身**：已按无损方案移除 14,115 个运行期不用的条目（`__pycache__`/pyc、site-packages 头文件、第三方 test 目录），Core 合并重复的 Python 3.12 运行时并做无损瘦身后，压缩包由 1,305.2 MB 降到 1,115.2 MB（约 -190 MB），解压后减少约 460 MB；提取测试与完整 `--test` 全绿（详见 `docs/CORE_DEPENDENCY_AUDIT_20261108.md`）。
12. **文档与字体/性能**：清理“309 个缩写串”“快捷键转录自 ChemDraw 26”等历史来源表述；字体不内置、调用系统字体 API；性能核对见 `docs/PERF_20261108.md`（画布悬停 0 次重绘，无整画布重复渲染）。

## 追加需求

- 选中结构右键新增“复制为 PNG”：透明背景 32bpp PNG（同时提供白底 CF_DIB 兼容格式），只复制选中内容，不改文档、不进撤销栈。
- OCSR 模块替换为用户提供的 2026-11-08 精简模块：审核、补齐 legal、重生成清单后使用，识别服务 1.3.1 已通过 ping/status/recognize 与苯环识别验证。重新打包后为 833,407,453 B（约 -44.6%，含 Pillow 解码与便携运行时修复）。

## 已知限制

- 新版本包尚未上传 GitHub Release；发布清单 `stable.json` 指向 `v0.9.6.0.0`，需先上传四个 ZIP 与新版安装器，再推送清单。
- CF_DIB 兼容格式为白底不透明（旧 Office/聊天工具）；需要透明背景时请使用 PNG 格式粘贴。
- 工具栏 hover 在全窗口 200% 缩放下仍有约 84 ms/次的既有 shell 重绘；画布本身无重复渲染。
- OCSR 的 legal 历史缺口（sentencepiece/tensorboard_data_server 许可文本、SOURCE_FILES 索引）为既有问题，建议后续单独闭合。

## 2026-11-08 二次修复（便携与中文路径）

- **修复“图片转结构”连不上本地识别服务**：界面判断运行时文件是否存在时使用窄字符 `std::ifstream`（UTF-8 路径在中文/非 ASCII 安装目录下打不开），改为宽字符 `GetFileAttributesW`；安装路径含中文时也能正常启动本地服务并完成识别。
- **OCSR 运行时便携化**：删除 venv 启动器（`ocsr_runtime/venv/Scripts`）与 `pyvenv.cfg`（旧包内是打包机绝对路径），统一用包内基础 Python + `PYTHONPATH` 启动；`ocsr_client.py`、`识别图片.cmd`、`recognize.cmd`、`启动OCSR服务.cmd` 与 AI 桥 `ai_ocsr_bridge.py` 同步修改。整个 OCSR 目录复制/剪切到任意位置或任意电脑都能直接运行，包内不再包含任何绝对路径。
- Core、AI 基础、图片识别包与在线安装器按新哈希重新打包，`stable.json` 与校验值同步更新；已在中文路径整机运行识别成功，并在全新目录解压、移动后完成 `--test` 两连绿与安装器全部自测。
- **修复安装 AI 基础时报“缺少 AI 运行时：ai/node.exe”**：安装器的 AI 健康检查把 AI 高级才提供的 Node 运行时当成 AI 基础必需文件，导致首次安装（含 AI 基础）在下载完成后中断并回滚。现在 AI 基础只校验桥接文件（ai_assistant.py 等），AI 高级才校验 ai/node.exe 与 ai_plugins 文件。
- **AI 基础单独安装也可用**：AI 入口可见性改为按 AI 基础桥接文件（ai_assistant.py）判断，不再要求 AI 高级的 DSH 运行时；只装 AI 基础时也可打开 AI 助手做基础对话/绘图，未装 AI 高级时“高级绘图”选项自动置灰并提示。
- **修复安装完成后不创建桌面快捷方式**：关闭运行时自检时，快捷方式创建被错误地一起跳过；现在安装完成总是按勾选创建，且检测到已安装、桌面缺少快捷方式时打开安装器会自动补建。
- **安装不再自动校验运行环境**：按组件安装完成后不再执行 Python 导入自检（rdkit/torch/scipy 等）与 Node 自检，安装完成即结束；需要时可运行安装器 `--health-test` 或应用内自检。
- **取消逐文件哈希，安装提速**：只校验四个 ZIP 的 SHA-256；解压不再对两万多个文件逐个算哈希，按大小复用已有文件，升级安装从分钟级降到十几秒，全新安装只剩解压/写入时间。
- **运行时 .pyc 不再导致升级失败**：`__pycache__/*.pyc` 由 Python 运行时重写，安装器不再把它当作被修改文件拒绝安装，也不写入安装清单。
- **修复“文件已被修改或不属于此组件”导致无法升级**：用热修复补丁替换过 MoleculeStudio.exe 的安装，此前会被安装器当作“用户修改文件”拒绝更新。现在程序二进制（exe/dll/pyd/node 等）在事务内允许替换并保留回滚备份；配置文件仍受保护。
- **并行/多线程下载恢复**：安装器重新按组件并行下载（所选组件同时下载、互不等待），每个文件在支持 Range 的服务器上使用 4 段并发连接，下载完成一个组件就立即安装该组件；界面恢复每个组件的独立进度条与状态行。
- **安装器镜像切换加固**：每个来源最多 3 次尝试（连接 20 秒、读取 30 秒超时），失败后在状态栏显示该来源的具体原因并自动切换下一个；全部失败时列出各来源错误，方便判断网络/代理问题。
- **修复 AI 入口丢失与设置页文字遮挡**：单运行时迁移后 AI 可用性检查仍要求旧 `python\python.exe`，导致“开始 AI 绘图”按钮被移除、AI 页只剩“AI 设置”；现改为按 `chemistry_backend.ini` 解析（chemistry_python，保留旧 python 回退）。设置 → AI 与 API 的 Skill 提示移至状态行下方，不再与“测试连接 / 另存 AI 绘图 Skill…”重叠。
- **修复 `CreateProcess failed, GetLastError=87`**：启动识别服务时构造的自定义环境块缺少结尾双 NUL，部分机器上 Windows 会读到缓冲区外并拒绝创建进程（同机时好时坏、换电脑必现），现已补齐；启动失败时日志会记录错误码与可读提示。
- **修复“新解压后第一次识别失败、跑一次旧版本后才正常”**：旧 exe 在 OCSR 缓存目录尚不存在时无法建立日志文件，会把识别服务的 stderr 并入通信管道；个别电脑上 Python/torch 的启动警告会冲掉协议行导致识别失败（缓存目录被旧版本建出来后即恢复）。现在首次启动会自动创建缓存目录、stderr 固定落盘，客户端只接受 `<` 开头的协议行；日志首行记录本次启动的 python/cache/records 路径，启动失败会记录 Windows 错误码。
