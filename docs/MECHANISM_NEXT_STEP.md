# 根据机理箭头生成下一步

在“图形”页用“机理箭头”连接电子来源和目标。起点和终点可吸附到原子或化学键中点；拖动时状态栏显示“原子 → 键”等绑定状态。框选同一步的箭头和反应物，点击独立“机理推演”栏的“生成下一步”。

程序同步计算全部选中双电子箭头，复制参与反应的完整连通结构，在右侧生成可编辑产物和反应箭头。原结构保留；生成和必要的页面扩展属于一次可撤销操作。无需调用模型或联网。AI 创建且端点绑定明确的机理箭头也可参与。

## 支持与边界

- 支持普通单、双、三键，C/N/O/H/卤素常见闭壳层电荷态的原子到原子、原子到相邻键、键到原子和相邻键之间的双电子移动。
- 同步修改键级和电荷，保留逐原子氢数，检查总电荷、合理价态和唯一的成键方向。不能通过补画隐式氢来掩盖不完整机理。
- 未参与变化的元素、芳香环及远端立体标记保留；反应中心涉及芳香键、非常规价态、自由基或立体标记时明确拒绝。缩写基团需先展开。
- 键来源的成键端存在多个合理解释时拒绝猜测。未绑定的机理箭头会按附近原子及整段化学键联合推断，允许教科书式留白；只有唯一的合理产物才会生成。漏画、重复、失效的已有引用、鱼钩箭头或真实歧义会明确弹窗提示，并保留完整选区。
- 分子间成键采用刚体排布，检查原子重叠、原子贴近非关联键和键交叉。分子内闭环需已有接近正常的成键距离；复杂环化暂不自动重排。

## 端点持久化

原生箭头参数携带语义来源/目标；CDXML 使用文件对象 ID 导出并在读取时重映射。复制结构和箭头时重映射引用；只复制箭头而未复制关联原子/键时清除引用；生成时可根据新位置附近的结构重新推断。移动分子不会自动重画旧箭头，生成前会检查端点是否仍在关联对象附近。未绑定的箭头可通过拖动端点重新吸附。

## 验收

`MoleculeStudio.exe --mechanism-step-check <目录>` 检查羟醛加成的准确连接关系、电荷和逐原子氢数、原结构保留、单步撤销/重做、原生手动端点吸附、复制引用重映射、CDXML 非连续 ID 往返、无效机理拒绝，以及旁观芳香环/含硫基团保留。


自然画法回归： --mechanism-infer-check <目录> 读取 input.cdxml，使用用户实际三根未绑定箭头验证键级、电荷、氢数、原图几何、撤销及保存重开。
