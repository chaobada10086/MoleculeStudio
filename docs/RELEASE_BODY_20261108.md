Windows x64 绿色版。Core 为必选，AI 基础 / AI 高级 / 图片识别按需安装；AI 高级必须依赖 AI 基础。

## 二、安装方法（手动解压）

1. 解压 Core，得到 `MoleculeStudio` 文件夹。
2. 如需要 AI 或图片识别，把对应 ZIP 内的 `MoleculeStudio` 文件夹与 Core 的**同名文件夹合并**，允许覆盖。
3. 安装顺序不影响结果，但 AI 高级只有在 AI 基础存在时才可运行。
4. 合并后 `MoleculeStudio.exe`、`ai/`（AI 高级）、`ai_plugins/`、`ocsr_service.py` 与 `ocsr_runtime/` 应位于同一个 `MoleculeStudio` 目录中。
5. 不要形成 `MoleculeStudio/MoleculeStudio` 的双层目录。
6. 双击 `MoleculeStudio.exe` 启动。

依赖关系：AI 基础依赖 Core；AI 高级依赖 AI 基础（进而依赖 Core）；图片识别依赖 Core。四个包的版本必须一致（0.95-20261108）。

## 三、本次版本主要内容

### 绘图与编辑

- **官能团表与自动大小写**：缩写目录扩充到 369 条源数据 / 361 条编译条目（新增 Bpin、pin、Ns、DIBAL、Li、MgBr、Cp、Tr、SnBu3 等）；修复 `cn` 因与元素符号冲突而不补全的问题，`cn → CN`（可展开氰基）、`bpin → Bpin`、`tbu → tBu` 等；精确元素符号（Co/Cn）保持原样；有歧义的键不猜测。完整清单见仓库 `docs/FUNCTIONAL_GROUPS.md`。
- **外部粘贴格式确认**：粘贴外部内容时，若键长/键宽/字体与当前文档不同，弹窗询问；默认采用复制源格式。画布为空时静默整体采用源格式；本程序内部复制不打扰。整个粘贴一次撤销。
- **命名与结构自动成组**：结构转命名自动把命名文字与结构编组；结构发生变化后命名文字出现红框，鼠标悬停提示“结构已经发生变动”；撤销/重做、原生与 CDXML 重载、解组行为正确。
- **文字默认字体**：新建文字默认 Arial 10（与 ChemDraw 默认一致）；无字体信息的 CDXML 导入回退 Arial；编辑旧文字不再污染新建默认字体。
- **文本格式操作**：框选文字对象后可直接点击字体/字号/加粗/斜体/下划线/上下标/颜色/对齐，无需先进入文本框编辑；支持组内文字与撤销。
- **工具栏默认展开**：初次安装/无配置时默认展开；用户保存过的收起偏好仍被尊重。
- **右键复制为 PNG**：选中结构右键新增“复制为 PNG”，生成透明背景 32bpp PNG（同时提供白底 CF_DIB 兼容格式），只复制选中内容，不改文档、不进撤销栈。

### AI

- **AI 未配置提示**：AI 助手窗口显示提示条与“配置 API”按钮，一键直达设置 → AI 与 API；配置补全后自动消失，发送/测试连接时也会提示。
- **AI 生成内容居中**：AI 本轮新增的结构/文字/箭头整体平移到当前可见画布中心；多对象整体居中；超出视口仅缩小不放大；既有对象不被搬动；一次撤销。
- **AI 基础单独安装也可用**：只装 AI 基础时，功能区 AI 标签页仍显示“开始 AI 绘图”和“AI 设置”，基础对话与绘图可用；未安装 AI 高级时“高级绘图”选项自动置灰，并在对话首行提示“高级绘图不可用，基础功能不受影响”。
- **AI 绘图 Skill**：Skill 随 Core 内置，设置 → “AI 与 API”或“更新与关于”页均可“另存 AI 绘图 Skill…”，不安装任何 AI 模组也能导出给外部 AI 使用。
- **AI 入口与设置页排版修复**：合并为单一 Python 运行时后，AI 可用性检查仍在找旧 `python\python.exe`，导致“开始 AI 绘图”入口消失、AI 标签页只剩“AI 设置”；现改为按 `chemistry_backend.ini` 解析实际解释器（chemistry_python，保留旧 python 回退）。另将设置 → “AI 与 API”页的 Skill 提示文字移到状态行下方，不再压住“测试连接 / 另存 AI 绘图 Skill…”按钮。
- **AI 基础/高级拆分**：基础组件只含助手桥接代码（约 74 KB），无需下载 DSH；高级组件才包含 DSH 运行时与高级绘图插件（约 758 MB），必须先装基础。

### 安装器与更新

- **四组件在线安装器**：四张卡片、依赖与安装/卸载顺序自动处理；勾选 AI 高级会自动带上 AI 基础；卸载 AI 基础会联动卸载高级；卸载 Core 包含全部模组。
- **AI 基础健康检查修复**：此前安装 AI 基础（或首次安装包含 AI 基础的组合）时，安装器把 AI 高级才提供的 `ai/node.exe` 当成 AI 基础的必需文件，导致安装报“缺少 AI 运行时：ai/node.exe”并中断。现在 AI 基础只校验自己的桥接文件，AI 高级才校验 Node 运行时与插件文件。
- **运行时生成的 .pyc 不再阻止升级**：`__pycache__/*.pyc` 会被 Python 运行时重写、哈希必然变化，安装器此前把它当成“文件已被修改”而停止。现在保留运行时副本、将其排除在安装清单之外，升级不再因此中断。
- **补丁版升级不再被拒**：安装器更新时允许替换被热修复或手动替换过的程序二进制（.exe/.dll/.pyd/.node 等，事务内备份、失败可回滚），解决“文件已被修改或不属于此组件”导致无法升级的问题；用户修改的配置/数据文件（ini/xml/cdxml 等）仍会停止安装并回滚，避免覆盖。
- **并行下载器恢复**：所选组件同时开始下载（每个组件一个下载任务，互不等待）；单个文件在服务器支持 Range 时使用 4 个连接分段下载，服务器不支持时自动回退单连接；每个组件下载完成即刻开始解压安装，界面为每个组件单独显示进度条、速度与状态。镜像自动切换与 SHA-256 校验保持不变。
- **下载镜像切换加固**：安装器在 GHFast / GH-Proxy / GHProxy.net / GitHub 之间自动切换（每个来源最多 3 次，连接 20 秒、读取 30 秒超时），每次失败会在状态栏显示该来源的具体原因并继续下一个；全部来源失败时错误信息会列出每个来源的失败原因，便于区分网络问题与镜像问题。
- **组件体积显示**：每张卡片显示发布版本与包体积，底部显示所选组件合计下载大小。
- **低分辨率修复**：1024×600、1366×768 以及 125%/150% 缩放下，卡片、安装位置、状态和底部按钮均可见可点；窗口按屏幕工作区自适应，内容可滚动、操作栏固定。
- **手动更新入口**：设置 → “更新与关于”提供“打开更新下载器…”，下载器随 Core 提供；只有用户点击才会启动，程序启动/打开设置/空闲时都**不会**自动检查更新或联网。

### 文档、字体与性能

- 清理说明文档中的历史来源表述（不再出现“309 个缩写串”“快捷键转录自 ChemDraw 26”等旧说法），以仓库自建目录与 `docs/FUNCTIONAL_GROUPS.md` 为准。
- 软件不内置、不分发任何字体文件；界面与画布文字改用系统字体 API（GDI+ 按字体族名），默认 Arial 10，避免字体再分发与侵权风险。
- 渲染性能核对：画布悬停 0 次重绘，拖动每帧仅一次画布绘制；没有“动一下就整画布重新渲染”的问题（数据见 `docs/PERF_20261108.md`）。
- Core 瘦身与 Python 去重：合并重复的 Python 3.12/3.10 双运行时为单一 3.10 运行时，并移除 `__pycache__`/pyc、site-packages 头文件、第三方 test 目录等运行期不用的条目，压缩包由 1.31 GB 降到约 1.04 GB，功能自检全绿。

### 界面与多语言

- 设置页次要按钮改为浅色底+描边，不再像普通文字；更新页新增“另存 AI 绘图 Skill…”按钮，点击直接打开另存窗口。
- 新增功能文案补齐 15 语言目录（简体/繁体中文、英文、日文、韩文、法/德/西/俄/葡/意等），不再出现中文硬编码。

## 四、OCSR 模块更新说明（替代 hotfix2）

- 本次图片识别使用 **2026-11-08 精简模块**：文件数约 3.4 万，压缩包约 795 MB（833,407,453 B；旧 OCSR 包约 1.5 GB，减小约 45%），保留 MolScribe 模型、Python 运行时、许可与来源材料。
- 服务版本升级到 **1.3.1**，保留并整合 hotfix1/hotfix2 的本地运行库补充、启动握手优化与错误日志；`ocsr_runtime/venv/pyvenv.cfg` 由安装器按实际安装路径重写，不再使用开发机绝对路径。
- **额外修复**：安装路径包含中文时，旧方案会让 OpenCV 读取模型输入图失败，出现识别无响应；现已把识别缓存改到 ASCII 临时目录，中文路径实测 `render + recognize` 成功。
- **启动方式加固**：不再依赖 venv 的 `pyvenv.cfg` 绝对路径，改用包内基础 Python 并通过 `PYTHONPATH` 加载 venv 依赖；复制到其他电脑/其他目录即使 `pyvenv.cfg` 失效也能启动。服务 stderr 写入 `%TEMP%\MoleculeStudio-OCSR-cache\service-error.log`，启动失败时界面会给出该日志路径。
- **去重**：Core 不再携带 `ai_dsh.py`（改由 AI 高级提供），四个 ZIP 解压合并时不会再出现重复文件提示。
- 已通过压缩包完整性、MANIFEST 逐文件校验、`ping`/`status`/`recognize`、苯环识别（6 原子/6 键）与安装器 `--extract-test` 验证。
- **重新打包（2026-11-08 二次修复）**：
  ① 修复“安装了图片识别却连不上本地识别服务”的问题：界面判断运行时文件是否存在时用了窄字符 `std::ifstream`（UTF-8 路径在中文/非 ASCII 安装目录下打不开），已改为宽字符 `GetFileAttributesW`，安装路径含中文也能正常启动服务；
  ② OCSR 运行时彻底去掉 venv 启动器与 `pyvenv.cfg`（旧包内是打包机绝对路径，复制到别的电脑会报 `No Python at …`），统一用包内基础 Python + `PYTHONPATH` 启动，命令行工具与 AI 桥同步修改；整个目录可复制/剪切到任意位置，包内不含任何绝对路径；
  ③ 服务端读取整页/裁剪图改为 Pillow 解码后以 RGB 数组送入 MolScribe，不再经由 OpenCV `imread` 读取文件；中文路径下 `render + recognize` 复验通过（10 原子/10 键）。
  ⑤ 修复个别机器上启动识别服务报 `CreateProcess failed, GetLastError=87`：自定义环境块缺少结尾双 NUL，Windows 会读到缓冲区外并拒绝创建进程（同类机器上时好时坏也源于此），现按规范补上双 NUL。
  ④ 全新解压/首次运行时自动创建 OCSR 缓存目录，识别服务的错误输出固定写入 service-error.log 而不再并入通信管道（个别电脑上 Python/torch 的启动警告会冲掉协议行，导致第一次识别失败）；客户端只接受 "<" 开头的协议行，杂行自动忽略；日志首行记录本次启动的 python/cache/records 路径，CreateProcess 失败会记录 Win32 错误码。
  Core、AI 基础、图片识别包与在线安装器（内置离线清单）均已按新哈希重新打包。
- 已安装旧 hotfix2 的用户：请直接使用本次 OCSR 新包（或四组件安装器）替换，旧 hotfix2 与启动器小补丁不再需要。

## 五、已安装用户如何更新

1. 保存文档并退出 MoleculeStudio，备份自己的配置、模板与自定义官能团。
2. 推荐运行新版 `MoleculeStudio-OnlineSetup.exe`，勾选需要更新的组件（AI 高级会自动带上 AI 基础），安装器会按清单校验并保留用户文件。
3. 也可以手动把四个新 ZIP 解压合并到原安装目录，允许覆盖；Core 与 AI/OCSR 的版本必须一致。
4. 在线清单 `updates/stable.json` 已更新为 schema2 四组件版本；旧安装器读取新清单会提示更新安装器，请使用本次附带的新安装器。

## 六、AI 与识别说明

- API Key 由使用者自行配置，发布包不含共享密钥。云端 AI 请求可能产生服务商费用，并将提示或所选附件发送到配置的服务商。
- OCSR 图片/PDF 识别在本地运行，不上传文献。识别可能出错，请对照原图检查原子、键级、手性、电荷和官能团；流程测试通过不代表识别结果一定正确。
- 不使用内置 AI 时，可从源码仓库 `skills/moleculestudio-draw` 获取外部 AI 绘图 Skill（也可在设置中直接另存）；基础文件绘图只需 Core，可生成可编辑 CDXML 后在软件中打开。
- 透明 PNG 复制仅对读取“PNG”注册格式的应用生效；旧 Office/聊天工具会使用白底 CF_DIB 兼容格式。
