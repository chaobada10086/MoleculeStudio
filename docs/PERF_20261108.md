# 渲染性能核对（2026-11-08）

## 方法

在最终构建（HEAD cc2d173，DX11 后端）上运行：

```powershell
out\Studio\MoleculeStudio.exe --bench out\bench-p6.txt
```

环境：3254×1745 窗口，DPI 缩放 200%，Direct3D 11 MSAA。

## 结果

| 场景 | 总耗时 | shell 绘制 | canvas 绘制 |
| --- | --- | --- | --- |
| 画布悬停 60 次（无拖动） | 1.46 ms | 0 次 | 0 次 |
| 画布拖动 60 次 | 296.4 ms | 0 次 | 60 次 / 274.6 ms |
| 工具栏悬停 20 次 | 1697.7 ms | 20 次 / 1685.9 ms | 1 次 / 7.2 ms |
| 连续画 20 个苯环 | 421.8 ms | 20 次 / 251.9 ms | 20 次 / 128.1 ms |

## 结论

- **画布不会因为鼠标移动/Hover 重绘**：悬停 60 次 canvas 绘制 0 次；拖动时只有 60 次画布绘制（每帧一次），没有整画布重复重建。
- 画布单帧综合耗时约 4.6 ms（274.6/60），对 200% 缩放的 4K 窗口属于正常范围。
- 工具栏（shell）悬停每个事件重绘一次工具条区域，200% 缩放下约 84 ms/次（1685.9/20），与新字体/文本改动无关，是既有工具条绘制路径；不涉及画布内容重排。若后续需要进一步优化，可缓存工具条背景/按钮层，本次不改动以避免回归。
- 文字改用系统字体（GDI+ 按字体族）后，画布悬停/拖动路径没有出现新增重绘；原有 cache/deferred 断言继续通过。
