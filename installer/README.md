# 在线安装器

Windows x64 / .NET Framework 4.8 在线安装器，使用 WPF 界面，无需管理员权限。

## 使用

运行 `dist/MoleculeStudio-OnlineSetup.exe`。打开后自动检测安装位置并获取在线版本清单，每张卡片独立显示未安装、已安装、安装不完整、清单异常或可更新。

四个组件卡片（核心工作台、AI 基础、AI 高级、图片识别）均可勾选，选中会出现大对勾和绿色边框；每张卡片显示发布版本与包体积，底部“将同时下载并安装”同时给出所选组件的合计下载体积。

安装采用并行下载：所选组件各自启动独立下载任务同时开始，不互相等待；服务器支持 Range 时每个文件用 4 个连接分段下载（不支持时自动回退单连接）；任一组件下载完成就立即开始解压安装。界面为每个组件单独显示进度条、下载速度与状态（排队/连接某来源/下载百分比/校验/安装/完成）。“安装 / 更新所选”批量处理未安装或可更新项，“卸载所选”批量处理已安装项；无可执行任务时按钮灰色。两种操作互相独立，未勾选不代表卸载。

依赖关系固定为：AI 基础依赖核心；AI 高级依赖 AI 基础（也必须先有核心）；图片识别依赖核心。勾选 AI 高级会自动把 AI 基础加入计划；AI 基础未安装/未勾选时 AI 高级不可安装并给出提示。安装顺序固定为 核心 → AI 基础 → AI 高级 → 图片识别；卸载顺序反向（图片识别 → AI 高级 → AI 基础 → 核心）。选择卸载核心时，计划会包含全部已安装模组；卸载 AI 基础会联动卸载 AI 高级。确认框明确列出计划，操作期间锁定其他按钮，用户文件和修改过的文件保留。

底部同时显示即将执行的顺序，并提供“打开软件”。“重新校验”执行完整哈希校验；启动状态检测依据清单、文件存在性和版本哈希，不等于已经完整校验全部内容。

- 核心：约 1.04 GB（已合并为单一 Python 运行时 + 无损瘦身：移除重复的 3.12 运行时、__pycache__/pyc、运行期不用的头文件与第三方 test 目录，功能自检全绿）。
- AI 基础：可选，约 74 KB；AI 助手/检索/对话画图的桥接代码，需要 Core 的运行时，需自行配置服务、模型和 API Key。
- AI 高级：可选，约 758 MB；包含内置 DSH（DeepSeek Harness）运行时、其第三方许可/源码材料与高级绘图插件，必须先安装 AI 基础。
- 图片识别：可选，约 795 MB（2026-11-08 精简模块，含本地模型；二次打包后 833,407,453 B，运行时已去除 venv 启动器与 pyvenv.cfg）。
- 全选首次下载约 2.56 GB（不含用户自备的 AI 服务费用）。安装器小不代表运行时或模型小。
- 2026-11-08 二次打包起，OCSR 运行时不再包含 `venv/Scripts` 与 `pyvenv.cfg`，安装器不再需要按安装路径改写该文件（`GeneratedConfig` 逻辑对旧包仍兼容，`--ocsr-config-test` 保留）。

成功安装后删除安装器缓存 ZIP，失败时保留已完成下载供重试。中断的单个包会从头下载（分段下载仅在单次尝试内并行，不跨次续传）。安装过程中请勿启动应用。

## 低分辨率与高缩放屏幕

窗口按当前屏幕工作区自动调整宽高（最大不超过可用区域），内容区可滚动，底部“安装 / 卸载”操作栏固定可见；在 1024×600、1366×768 以及 125% / 150% 系统缩放下，四张卡片、安装位置、状态与操作按钮都可以完整看到并点击。EXE 内嵌 DPI 感知清单（PerMonitorV2），不会因高 DPI 出现模糊或控件跑出窗口。可用 `--small-screen-test` 自动验证。

## 复用与保护

已有安装依据 `.installer-*.json` 或 `MANIFEST-*.json` 逐文件校验 SHA-256，完整组件跳过下载和解压。原始 0.95 Core 识别为可更新版，更新时按旧清单保护文件。清单缺失时仍可复用下载缓存和逐文件相同内容，但不会仅凭目录存在就判为完整。

检查范围是用户选择的安装目录，不扫描或接管系统、Conda、其他软件的 Python。最终执行 RDKit / torch / scipy / pandas / CSP5 导入自检，不修改系统安全设置。

OCSR 的基础解释器及 site-packages 与核心 chemistry_python 文件哈希完全相同时使用 NTFS 硬链接节省磁盘空间；不能创建硬链接时复制。不是跨版本混用 Python。共享文件后应由安装器维护，不要直接对共享运行时执行 pip 升级或原地修改二进制。

在线清单来自官方 HTTPS 地址，仓库文件及发布步骤参见 [updates/README.md](../updates/README.md)。获取失败时明确显示使用内置版本、未确认最新。

更新时只替换旧清单管理且未被修改的文件，批量安装失败会恢复本次更改；异常退出后再次启动自动恢复。更新日志先落盘，再替换文件，提交完成后清理备份。发现用户修改或未知同名文件会停止并回滚，避免覆盖配置。支持按清单移除组件，仅删除未修改的托管文件，保留其他组件共享路径及用户文件。

## 版本清单兼容

安装器支持两种清单：

- `schema=2` / `min_installer_protocol=2`：四组件清单（Core、AIBasic、AIAdvanced、OCSR），可表达 AI 高级及其依赖；当前推荐格式。
- `schema=1` / `min_installer_protocol=1`：旧的三组件清单（Core、AI、OCSR），仍可读取；其中 AI 视为 AI 基础，AI 高级显示为“需要新版清单，暂不可用”。

安装器拒绝未知组件、重复组件、缺失依赖、依赖环、协议版本高于自身以及非官方来源的 URL/校验值。升级安装器后可以读取更高协议版本；旧安装器会明确提示需要更新。

## 下载来源

下载按组件并行进行，镜像切换在单个组件的下载任务内完成。默认 GHFast → GH-Proxy → GHProxy.net → GitHub，镜像失败后自动切换，GitHub 最后备用。取消“镜像优先”则只使用 GitHub。第三方来源可能不可用；每个来源最多三次尝试（连接 20 秒、读取 30 秒超时），每次失败会在状态栏显示该来源的具体原因并继续切换；全部失败时错误信息会列出每个来源的失败原因，便于判断是网络还是镜像问题。所有 ZIP 必须匹配官方版本清单（离线回退时为内置清单）的 SHA-256，错误内容不会解压。不关闭 TLS 校验，不执行镜像返回的脚本。

备用服务文档：[GH-Proxy](https://gh-proxy.com/en/docs/github-accelerator/)、[GitHub Releases 代理说明](https://doc.oplist.org/guide/drivers/github_releases)。可取消勾选，仅使用 GitHub。安装器 EXE 和窗口使用项目原有 MoleculeStudio 图标。

## 构建与验证

运行 `python installer/build.py`，使用系统 .NET Framework C# 编译器生成 `dist/MoleculeStudio-OnlineSetup.exe`（嵌入 DPI 感知应用清单）。无需 pip / npm。

- `--self-test`：路径越界、重复安装、硬链接、修改冲突等基础安全用例。
- `--health-test 安装目录 [组件序号]`：验证组件运行时（默认 0=Core 化学运行时；1=AI 基础桥接文件；2=AI 高级 Node 运行时与插件）。
- `--extract-test 组件序号 ZIP路径 测试目录`：用真实发布包验证哈希、解压及安装清单；序号 0 Core / 1 AIBasic / 2 AIAdvanced / 3 OCSR。
- `--ocsr-config-test`：验证 OCSR 的 pyvenv.cfg 路径重写、回滚与校验。
- `--feed-test 清单 [清单2]`：验证 schema1/schema2 解析、依赖闭合、旧协议拒绝与恶意 URL 拒绝。
- `--batch-test`：验证组合选择、依赖顺序、卸载联动与计划顺序。
- `--dependency-test`：验证 AI 高级必须依赖 AI 基础。
- `--lifecycle-test`：验证模组移除、共享路径保留、用户修改保留、完整卸载与再次添加。
- `--rollback-test`：验证更新、异常退出恢复以及用户文件保留。
- `--small-screen-test`：在 1024×600 及高 DPI 模拟下断言四张卡片与底部操作栏都在客户区内可点击。
- `--parallel-test`：构造四个本地夹具组件，验证并行下载、逐个安装、共享文件与事务提交/校验。
- `--download-test URL SHA256 字节数`：用下载器下载指定 URL 并核对 SHA-256；配合支持 Range 的本地服务器可验证 4 线程分段下载与单连接回退。
- `--preview 输出PNG [WIDTHxHEIGHT] [select] [--jobs] [安装目录]`：渲染界面预览，可指定尺寸；`--jobs` 额外渲染每个组件各自的下载/安装进度行。

EXE 未做商业代码签名。Windows 的 Smart App Control 仍可能拦截安装器或依赖，不能保证所有目标机器放行。

默认勾选创建桌面快捷方式，批量安装成功后创建指向 MoleculeStudio.exe 的快捷方式，配置工作目录及应用图标。卸载只清理本安装器创建且仍指向该安装位置的快捷方式。重复安装不重复创建；同名快捷方式指向其他位置时使用带位置标识的名称。取消勾选只是不新建，不删除已有快捷方式。
