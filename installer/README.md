# 在线安装器

Windows x64 / .NET Framework 4.8 在线安装器，使用 WPF 界面，无需管理员权限。

## 使用

运行 `dist/MoleculeStudio-OnlineSetup.exe`。打开后自动检测安装位置并获取在线版本清单，每张卡片独立显示未安装、已安装、安装不完整、清单异常或可更新。

三个组件卡片均可勾选，选中会出现大对勾和绿色边框。“安装 / 更新所选”批量处理未安装或可更新项，“卸载所选”批量处理已安装项；无可执行任务时按钮灰色。两种操作互相独立，未勾选不代表卸载。

缺少当前完整核心时，安装计划自动把核心放在最前，核心下载、安装和自检完成后才处理模组。选择核心卸载时，计划会包含已安装模组，确认框明确列出，执行顺序固定 OCSR → AI → Core。操作期间锁定其他按钮，用户文件和修改过的文件保留。

底部同时显示即将执行的顺序，并提供“打开软件”。“重新校验”执行完整哈希校验；启动状态检测依据清单、文件存在性和版本哈希，不等于已经完整校验全部内容。

- 核心：当前清单为 0.95 issue2 hotfix，下载约 1.41 GB。
- AI：可选，下载约 814 MB。
- OCSR：可选，下载约 1.57 GB。
- 全选首次下载约 3.79 GB。安装器小不代表运行时或模型小。

成功安装后删除安装器缓存 ZIP，失败时保留已完成下载供重试。中断的单个包会从头下载，不宣称支持断点续传。安装过程中请勿启动应用。

## 复用与保护

已有安装依据 `.installer-*.json` 或 `MANIFEST-*.json` 逐文件校验 SHA-256，完整组件跳过下载和解压。原始 0.95 Core 识别为可更新版，更新时按旧清单保护文件。清单缺失时仍可复用下载缓存和逐文件相同内容，但不会仅凭目录存在就判为完整。

检查范围是用户选择的安装目录，不扫描或接管系统、Conda、其他软件的 Python。最终执行 RDKit / torch / scipy / pandas / CSP5 导入自检，不修改系统安全设置。

OCSR 的基础解释器及 site-packages 与核心 chemistry_python 文件哈希完全相同时使用 NTFS 硬链接节省磁盘空间；不能创建硬链接时复制。不是跨版本混用 Python。共享文件后应由安装器维护，不要直接对共享运行时执行 pip 升级或原地修改二进制。

在线清单来自官方 HTTPS 地址，仓库文件及发布步骤参见 [updates/README.md](../updates/README.md)。获取失败时明确显示使用内置版本、未确认最新。

更新时只替换旧清单管理且未被修改的文件，批量安装失败会恢复本次更改；异常退出后再次启动自动恢复。更新日志先落盘，再替换文件，提交完成后清理备份。发现用户修改或未知同名文件会停止并回滚，避免覆盖配置。支持按清单移除组件，仅删除未修改的托管文件，保留其他组件共享路径及用户文件。

## 下载来源

默认 GHFast → GH-Proxy → GHProxy.net → GitHub，镜像失败后自动切换，GitHub 最后备用。取消“镜像优先”则只使用 GitHub。第三方来源可能不可用；每个来源最多两次尝试，全部失败后提示重试。所有 ZIP 必须匹配官方版本清单（离线回退时为内置清单）的 SHA-256，错误内容不会解压。不关闭 TLS 校验，不执行镜像返回的脚本。

备用服务文档：[GH-Proxy](https://gh-proxy.com/en/docs/github-accelerator/)、[GitHub Releases 代理说明](https://doc.oplist.org/guide/drivers/github_releases)。可取消勾选，仅使用 GitHub。安装器 EXE 和窗口使用项目原有 MoleculeStudio 图标。

## 构建与验证

运行 `python installer/build.py`，使用系统 .NET Framework C# 编译器生成 `dist/MoleculeStudio-OnlineSetup.exe`。无需 pip / npm。

`--self-test` 检查路径越界、重复安装、硬链接及修改冲突；`--health-test 安装目录` 验证化学运行时；`--extract-test 组件序号 ZIP路径 测试目录` 用真实发布包验证哈希、解压及安装清单（0 Core / 1 AI / 2 OCSR）；`--preview 输出PNG` 渲染界面预览。

EXE 未做商业代码签名。Windows 的 Smart App Control 可能仍拦截安装器或依赖，不能保证所有目标机器放行。

组件管理专项测试：`--lifecycle-test` 验证模组移除、共享路径保留、用户修改保留、完整卸载与再次添加。自动检测快速读取组件清单；执行安装前再进行完整哈希校验。

默认勾选创建桌面快捷方式，批量安装成功后创建指向 MoleculeStudio.exe 的快捷方式，配置工作目录及应用图标。卸载只清理本安装器创建且仍指向该安装位置的快捷方式。重复安装不重复创建；同名快捷方式指向其他位置时使用带位置标识的名称。取消勾选只是不新建，不删除已有快捷方式。

新增测试：`--batch-test` 验证组合选择与依赖顺序；`--feed-test updates/stable.json` 验证清单与来源约束；`--rollback-test` 验证更新、异常退出恢复以及用户文件保留。
