## 产品名称

MoleculeStudio

## 简短描述（前 270 字符最关键）

绘制分子结构、反应机理与催化循环，保存为可继续编辑的 CDXML。可选的离线图片转结构，以及使用你自己服务商的 AI 助手。

## 详细描述

**在线 AI 功能需要你自己提供第三方服务的 API Key。全部绘图、计算与离线图片识别都无需账号、无需密钥、无需联网即可使用。**

MoleculeStudio 是面向化学工作者、教师与学生的结构绘图工作台。原生 Windows x64 程序：Direct3D 画布、无浏览器内核、无订阅。

能画什么
- 原子、键、电荷、自由基、孤对电子、立体化学（楔形/虚线键、R/S、E/Z）
- 环、链、常见官能团模板与命名试剂库
- 反应式与电子转移箭头、催化循环、底物支线
- 演示图与流程图：标题、节点、分支、连线、手绘曲线，全部可继续编辑

离线且免费的部分
- 本地化学计算（分子式、分子量、元素分析），随包提供运行环境
- 本地图片/PDF 转结构：粘贴论文里的反应式截图即可得到可编辑结构，全程在本机完成，图片不外传
- 聚合物/生物分子/试剂模板库与缩写词库

可选的在线 AI
填入服务地址、模型名和你自己的 API Key 后，助手可以按描述绘图、执行反应步骤、整理版面。程序不会在后台联网；费用由你选择的服务商收取，与开发者无关。

重要限制
- 机器识别的结构务必核对：键级、电荷、手性可能识别错误，发表前请人工确认
- 在线助手的能力取决于你接入的模型，AI 输出可能有误
- 本程序是科研绘图工具，不作为法规或安全判定的依据

文件格式
读写 ChemDraw CDXML 与自有 .r62doc；结构可嵌入 Word / PowerPoint 并作为可编辑对象双击修改。

## 功能要点

- 原生 x64 Direct3D 画布，大文档依然流畅
- CDXML 与 ChemDraw 互相往返，另有自有格式
- 反应机理：电子转移箭头、催化循环、底物支线
- 演示图与流程图，图形/文字/曲线均可编辑
- 本地离线的图片与 PDF 结构识别（不联网、不要密钥）
- 随包的本地化学计算
- 嵌入 Word / PowerPoint 的可编辑 OLE 对象
- 可选 AI 助手，自备服务商与密钥
- 中英文界面

## 系统要求

- Windows 10 版本 2004（19041）及以上，或 Windows 11；x64
- 支持 Direct3D 11 的显卡（不可用时自动回退）
- 4 GB 内存，3 GB 可用磁盘空间
- 需要 OLE 嵌入时使用 Word / PowerPoint 2016 或更新版本（可选）
