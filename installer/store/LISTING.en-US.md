## Product name

MoleculeStudio

## Short description (first 270 characters matter)

Draw molecules, reaction mechanisms and catalytic cycles, save them as editable CDXML. Optional
offline image-to-structure recognition, and an AI assistant that works with your own provider.

## Description

**Online AI features require your own third-party API key. All drawing, calculation and offline
image recognition works without any account, key or network connection.**

MoleculeStudio is a structure drawing workbench for chemists, teachers and students. It is a
native Windows x64 application: fast Direct3D canvas, no browser engine, no subscription.

WHAT YOU CAN DRAW
- Atoms, bonds, charges, radicals, lone pairs, stereochemistry (wedges, hashes, R/S, E/Z)
- Rings, chains, templates for common functional groups and named reagents
- Reaction schemes with electron-pushing arrows, catalytic cycles and substrate branches
- Presentation figures: titles, nodes, branches, connectors and hand-drawn curves, all editable

WHAT YOU GET FOR FREE, OFFLINE
- Local chemistry calculations (formula, molecular weight, elemental analysis) using a bundled runtime
- Local image/PDF to structure recognition: press a button on a screenshot or scan of a paper
  scheme and get an editable structure. Runs entirely on your machine; no image ever leaves it.
- A polymer/biomolecule/reagent template library and a nickname library

OPTIONAL ONLINE AI
If you configure an endpoint, model name and your own API key, the assistant can draw from a
description, apply reaction steps, or tidy a layout. The app never contacts a network unless you
ask it to. Provider usage is billed by that provider, not by us.

IMPORTANT LIMITATIONS
- Always verify machine-recognised structures: bond orders, charges and stereochemistry can be
  misread. Review before using in publication.
- The online assistant depends entirely on the model you connect; AI output can be wrong.
- Chemistry is a scientific tool, not a calculator for regulatory or safety decisions.

FILE FORMATS
Open and save ChemDraw CDXML, plus the native .r62doc format. Structures embed into Microsoft
Word and PowerPoint as editable OLE objects.
